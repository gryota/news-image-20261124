A 1024x1024 newspaper-style poster summing up Tuesday, 24 November 2026 in four stories: Nvidia brings Jensen Huang back as CEO after Trump intervenes, the US blacklists Singapore chip firm Megaspeed in the Nvidia scandal, Iran demands $290 billion as a tanker hits a mine in the Strait of Hormuz, and Russian jets enter South Korea's air defence zone. Drawn from scratch with Python + Pillow — every illustration is original, no photos or downloaded assets — and fully deterministic: two runs produce byte-identical output. The drawing code is in `draw_poster.py`; `main.py` (standard library only) copies the pre-rendered `entry.png` to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
